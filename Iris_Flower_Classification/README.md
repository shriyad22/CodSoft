# Iris Flower Classification

## Overview

This project focuses on classifying Iris flowers into three different species—Setosa, Versicolor, and Virginica—using Machine Learning techniques. The classification is based on the physical measurements of the flowers, including sepal length, sepal width, petal length, and petal width.

## Objective

To build a machine learning model that can accurately predict the species of an Iris flower based on its features.

## Dataset

The Iris dataset contains 150 observations with the following features:

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width
* Species (Target Variable)

### Species Included

* Iris Setosa
* Iris Versicolor
* Iris Virginica

The dataset was analyzed using:

* Pair Plot

These visualizations helped in understanding feature relationships and model performance.

## Machine Learning Model

**Algorithm Used:** Random Forest Classifier

The Random Forest algorithm was selected due to its high accuracy and ability to handle classification tasks effectively.

## Results

The model achieved high classification accuracy on the test dataset and successfully identified Iris flower species based on flower measurements.

## Conclusion

This project demonstrates the complete machine learning workflow, from data preprocessing and visualization to model training and evaluation. The Random Forest Classifier proved effective in accurately classifying Iris flower species.
